## github.com/faustbrian/go-http-client/v3

`http-client` is a policy layer for typed outbound HTTP integrations. It is built on `net/http`, preserves standard requests and responses, and is neutral about vendor models and payload codecs.

| Import path | Responsibility |
| --- | --- |
| [`github.com/faustbrian/go-http-client/v3`](../auth.go) | Use for bounded outbound HTTP transport, request construction, authentication, middleware, response ownership, and explicitly selected HTTP policy. |
